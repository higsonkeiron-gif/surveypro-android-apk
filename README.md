# SurveyPro Android Project

This repository contains the Android source code and automated GitHub Actions workflow to build `app-debug.apk`.

## Building the APK

1. Push these files to the root of a GitHub repository (or use the 1-Click Cloud APK Compiler in SurveyPro Studio).
2. Open the **Actions** tab in GitHub and run **Build SurveyPro APK**.
3. Download `SurveyPro-debug-apk` from the workflow run artifacts.
